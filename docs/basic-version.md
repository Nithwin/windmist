# Basic Version Summary

This branch keeps WindMist very simple.

It includes:

- one terminal chat command
- one default provider: Gemini
- a small set of file tools
- a beginner-friendly build guide

It does not try to explain or expose the more advanced ideas from the larger version.

If you are learning the project for the first time, start with:

1. [README.md](../README.md)
2. [docs/build-windmist.md](build-windmist.md)

That will give you the shortest path through the code and the docs.
