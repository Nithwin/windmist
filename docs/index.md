# Welcome to WindMist

WindMist is a powerful, terminal-based AI coding assistant designed to bring agentic intelligence directly into your workflow without leaving the CLI.

## Key Features

- **Multi-Provider AI**: Use Anthropic, OpenAI, Gemini, or local models via Ollama.
- **Agentic Tools**: WindMist can read files, edit code, run terminal commands, and perform web searches natively.
- **RAG & Memory**: Intelligent codebase semantic search and sliding-window context management.
- **Sub-Agents**: Spawn cheaper models in the background to summarize, research, or analyze architecture.

Head over to the [Getting Started](getting-started.md) guide to install WindMist!
